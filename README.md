# 📌 Guys and Gals Salon Inventory Management System and POS

An Inventory Management and POS system for Guys and Gals Salon

---

## 📖 Project Description

This project aims to provide Guys nad Gals Salon an Inventory Management system and POS system. This project allows you to manage product inventory, POS system, track daily and total income, track users, and track the amount of customers served.

---

## 🚀 Features (CRUD)

### ✔ Create
-Add users
-Add products

### ✔ Read
-Displays product information
-Displays user information whether it is admin or cashier.

### ✔ Update
-Update product information
-update user information
### ✔ Delete
-Delete products in the inventory
-Delete users
