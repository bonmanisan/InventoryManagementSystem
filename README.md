# 📌 Guys and Gals Salon Inventory Management System and POS

An Inventory Management and POS system for Guys and Gals Salon

---

## 📖 Project Description

This project aims to provide Guys and Gals Salon an Inventory Management system and POS system.  
It allows the management of product inventory, POS transactions, daily and total income tracking, user accounts, and the number of customers served.

---

## 🚀 Features (CRUD)

### ✔ Create
- Add users  
- Add products  

### ✔ Read
- Display product information  
- Display user information (admin or cashier)  

### ✔ Update
- Update product information  
- Update user information  

### ✔ Delete
- Delete products from the inventory  
- Delete users
